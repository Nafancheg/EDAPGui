# ED Autopilot — EDAPGui (форк)

Автопилот для Elite Dangerous: компьютерное зрение (скриншоты + YOLO/шаблоны + OCR) и эмуляция клавиатуры. Игру не модифицирует — работает как «внешний пилот».

Это форк [SumZer0-git/EDAPGui](https://github.com/SumZer0-git/EDAPGui) с исправлениями наведения, защитой от перегрева, EDSM-интеграцией, мини-панелью, режимом быстрого перелёта и русской локализацией. Список изменений — в [ChangeLog.md](ChangeLog.md). Оригинальный README — [docs/README.en.md](docs/README.en.md).

## Возможности

### Основные ассисты

| Ассист | Описание |
|---|---|
| **FSD Route Assist** | Выбираете маршрут в галактической карте — автопилот выполняет все прыжки: обход звезды, дозаправка скупом, наведение, прыжок. Опционально honk (дискавери-скан) и сканер ELW. |
| **Supercruise Assist** | Держит цель по центру в суперкруизе, по «PRESS TO DISENGAGE» выходит из SC, запрашивает стыковку и передаёт управление автодоку. Обрабатывает интердикцию и окклюзию станции планетой. |

### Новое в этом форке (07/2026)

- **Мини-панель поверх игры** — компактная always-on-top панель (кнопка в блоке MODE): переключатели FSD/SC, СТОП, БЫСТРО и полный блок статуса как в оверлее (обновление раз в секунду). Перетаскивается мышью за заголовок.
- **Режим «Быстрый перелёт» (FastTravelMode)** — пропускает honk, FSS/ELW-сканирование и паузы на остывание (если нет перегрева). Для задач «просто быстро долететь».
- **EDSM-проверка систем** — после каждого прыжка фоновый запрос к EDSM: если системы нет в базе, оверлей/панель подсвечивают «возможно неоткрытая система» (плюс голос) — сигнал остановиться и сканировать. Для известных систем показывает число тел, сколько ещё не открыто, первооткрывателя и ценные тела (ELW/WW/AW/терраформируемые). Опция `EDSMCheckEnable`.
- **Защита от перегрева** — флаг перегрева из Status.json проверяется при наведении, компасном выравнивании, проходе мимо звезды и на всех этапах заправки. При перегреве: аварийный отворот от звезды на полном газу до остывания.
- **Исправленное наведение** — устранены вечные циклы при наведении на планету (лимит репозиций при окклюзии, таймаут выравнивания, рабочая проверка «цель позади», выбор лучшего ML-совпадения). Перед гиперпрыжком используются широкие допуски (`jump_align_*` — FSD сам центрует в конусе), что убирает раскачку.
- **Оверлей** — топливо, скупаемость звезды, цель с остатком прыжков, дистанция, ETA, строка EDSM.
- **Русская локализация** оверлея, голосовых сообщений и новых элементов GUI (`locales/ru.json`, `"Language": "ru"` в configs/AP.json).
- **Логи** — в папке `logs/`, автоматическая ротация (хранятся 10 последних).

### Дополнительные возможности

- **ELW Scanner** — при FSD-перелёте заглядывает в FSS и по спектру определяет наличие землеподобных/водных/аммиачных миров; объявляет голосом и пишет в `elw.txt` (систему нужно потом просканировать вручную — автопилот кредит за скан не получает). Требует калибровки региона под ваше разрешение.
- **Auto-tune RPY** — автоматическая калибровка кривых скоростей поворота корабля (roll/pitch/yaw) по фактическим замерам. Защищён от зашумлённых замеров.
- **Профили кораблей** — `configs/ship_configs.json`: скорости RPY и `SunPitchUp+Time` (доворот от звезды при заправке; положительное значение — для греющихся кораблей, отрицательное — для холодных).
- **Голосовое сопровождение** (русский — при русском TTS-голосе Windows).
- **Интердикция** — автоматический уход при перехвате.
- **Горячие клавиши** — Home/Ins/End и т.д. (настраиваются): старт FSD/SC ассистов, стоп всех.
- **Калибровка** — подбор масштаба шаблонов под ваше разрешение: [docs/Calibration.md](docs/Calibration.md).
- **`DisengageUseMatch`** — старое шаблонное распознавание «PRESS TO DISENGAGE» вместо OCR (оставлено как запасной вариант).

> **В процессе расчистки/декомпозиции (ветка `cleanup-decompose-avionics`):** как периферийные, не относящиеся к ядру полёта, удалены: Robigo Assist, AFK Combat Assist, TCE Integration, Waypoint Assist (+ редактор), Single Waypoint Assist, DSS Assist, Galaxy/System Map, редактор колонизации, экспериментальный Auto-FSS и внешний канал управления **EDMesg** (ZeroMQ) — вместе с их парсерами/тестами. Ядро полёта также разложено из монолита `ED_AP.py` на модули `services/` (топливо/навигация/прыжки/докинг/ELW-советник). См. `ChangeLog.md`.

## Требования

- **Windows** (Linux не поддерживается), Elite Dangerous в режиме **Borderless**.
- **Python 3.11** (рекомендуется 3.11.9).
- Стандартные **цвета HUD** (изменённые цвета ломают распознавание).
- Максимальная **яркость интерфейса** (правая панель → SHIP → INTERFACE BRIGHTNESS) и LOCATION STATUS ICONS = SHOW ICONS.
- Модуль **Advanced Autodocking** на корабле (для стыковки), топливозаборник (для заправки).
- Во время работы ассиста фокус должен быть на окне игры (автопилот шлёт клавиши в активное окно).
- Обязательные привязки клавиш — таблица в [docs/README.en.md](docs/README.en.md#required-keybindings); отсутствующие привязки пишутся предупреждениями в `logs/autopilot.log`.

## Установка

```bat
git clone <этот репозиторий>
cd EDAPGui
py -3.11 -m venv venv
venv\Scripts\pip install -r requirements.txt
```

Либо просто запустить `start_ed_ap.bat` — он установит всё сам.

## Запуск

1. Запустите Elite Dangerous (Borderless).
2. Запустите `start_ed_ap.bat` (или `python EDAPGui.py`).
3. Первый запуск: выполните калибровку экрана ([docs/Calibration.md](docs/Calibration.md)), проверьте привязки клавиш (предупреждения в логе), выполните калибровку RPY корабля (блок SHIP).
4. Выберите цель в галактической карте → включите FSD Route Assist (или клавиша Home).
5. Для управления поверх игры: кнопка «Мини-панель» в блоке MODE.

## Настройки

- `configs/AP.json` — все параметры автопилота (создаётся автоматически). Ключевые: `Language`, `FastTravelMode`, `EDSMCheckEnable`, `ElwScannerEnable`, `RefuelThreshold`, `FuelScoopTimeOut`, `jump_align_outer_lim`/`jump_align_inner_lim`, тайминги `Wait_*`.
- `configs/ship_configs.json` — персональные профили кораблей.
- Языки: `locales/*.json` (en/ru полные, de/es/fr — заглушки). Язык также определяет строки OCR — язык игры должен соответствовать.

## Известные ограничения

- Шаблоны сняты на 3440x1440 — другие разрешения требуют калибровки.
- Большой FOV (Graphics → Display) увеличивает элементы — шаблоны могут не совпасть; рекомендуется 10–15% слайдера.
- Двойные звёзды рядом друг с другом — риск перегрева (сейчас смягчён аварийным отворотом, но риск остаётся).
- «Economical» роутинг ставит звёзды не по курсу — засветка консоли мешает компасу; рекомендуется «Fastest».
- Левая панель должна быть на вкладке Navigation.
