ПЛАН ПРОВЕРКИ WEB-MCDU

Один пункт = одна страница MCDU и одна проверка. Синяя метка — какую клавишу прибора нажать, дальше — что сделать, серым — что должно появиться. Рулите вручную, автопилот не включаем. При «НЕ ОК» пишите в поле, что увидели вместо ожидаемого. В конце — «СКОПИРОВАТЬ ОТЧЁТ».

БЛОК 1Телеметрия — по одной странице
  • PROGОткрывается при загрузке. Стрелками ←/→ долистать до фазы CRUISE (активная подсвечена сама)справа: ПРЫЖКИ n/m, ЦЕЛЬ, ТОПЛИВО % — числа совпадают с игрой
  • INITНажать клавишу INIT, просто посмотреть правую колонкуDEST (или NO ROUTE, если маршрут не проложен), JUMPS, SHIP — ваш корабль, FUEL %, LINK — CONNECTED
  • DATAНажать клавишу DATASYSTEM — система, где вы сейчас; STAR — класс звезды и SCOOP/✗. До первого прыжка за сессию STAR может быть «---» — класс звезды приходит из журнала после прыжка, это норма
  • PROGВ игре открыть галкарту и выбрать любую систему целью (без прокладки маршрута)строка ЦЕЛЬ на PROG сменилась на выбранную систему за ~1–2 с
  • PROGПрыгнуть в выбранную систему вручнуюна PROG (фаза CRUISE): счётчик прыжков +1, ДИСТ выросла; на DATA поле SYSTEM сменилось на новую систему и STAR заполнился
  • FUEL PREDНажать клавишу FUEL PRED (после 2–3 прыжков)FUEL % и тонны упали после прыжка; появились СРЕДН/ПРЫЖОК и ДО ЗАПРАВКИ N; при скупе у звезды уровень растёт; лампочка на клавише соответствует состоянию
  • ЛОГПанель под экраном приборастроки событий появляются по ходу полёта. Лог живёт в странице: после перезагрузки страницы (F5) он пустой — это норма, не баг
БЛОК 2F-PLN — маршрут, проложенный в игре
  • F-PLNВ игре проложить маршрут по галкарте (несколько прыжков), нажать клавишу F-PLNсписок систем с классами звёзд и LY; текущая помечена; внизу DEST и TOTAL N JMP; стрелки ↑/↓ мотают список
  • F-PLNПрыгнуть на один прыжок по этому маршрутуотметка текущей системы сдвинулась на следующую строку
  • F-PLNОтменить маршрут в галкартевместо списка — НЕТ АКТИВНОГО МАРШРУТА / ПРОЛОЖИ В ГАЛАКАРТЕ
БЛОК 3RTE PLAN — наш построитель (Spansh, нужен интернет)
  • RTE PLANПроложить в игре маршрут (для подстановки), нажать клавишу RTE PLANполе DEST уже заполнено конечной системой игрового маршрута
  • RTE PLANНажать LSK у PLOT FUEL-SAFEмигает ПОСТРОЕНИЕ··· 10–30 с, затем заполняются JUMPS P/S и DIST P/S; в заголовке плана — имя ВАШЕГО корабля
  • RTE PLANНажать LSK у RTE LISTсписок систем плана листается; заправочные остановки помечены (RFL/SCOOP); L6 RETURN возвращает
  • RTE PLANНажать LSK у PLOT FAST/RISKYмаршрут перестроился, RISK — HIGH (нейтронные плечи)
  • RTE PLANНабрать в скретчпаде мусор (например KLDSFJH99), нажать LSK у DEST, затем PLOTвнятная ошибка (INVALID / unknown system), прибор не завис
БЛОК 4Исполнение построенного маршрута — рулите сами
Для этого блока постройте короткий FUEL-SAFE маршрут на 3–5 прыжков. Теперь после каждого прыжка прибор САМ откроет галкарту, наберёт следующую систему в поиске и проложит к ней метку (1 прыжок) — в этот момент уберите руки с клавиатуры и мыши. Прыгаете по метке вы, вручную. Если метка не встала — в логе будет MAP TARGET FAILED, ставьте руками.
  • RTE PLANНажать ACTIVATE SEC, затем ещё раз (появится ТОЧНО?)флэш SEC АКТИВИРОВАН; статус ACTIVE n/m; прибор сам открыл галкарту, набрал первую систему плана и поставил метку (в логе MAP TARGET OK), карта закрылась
  • RTE PLANПрыгнуть по выставленной метке. Повторить пару разпосле каждого прыжка: счётчик n/m +1, NEXT сменился, ▶ в RTE LIST сдвинулся, и прибор сам перевыставил метку на следующую систему (MAP TARGET OK в логе)
  • RTE PLANПрыгнуть в систему НЕ из плана, потом вернуться на маршрутфлэш ВНЕ МАРШРУТА и статус OFF ROUTE; после возврата — снова ACTIVE
  • RTE PLANДолететь до конечной системы планафлэш МАРШРУТ ЗАВЕРШЁН, статус COMPLETE
  • RTE PLANПостроить и активировать ещё раз, затем STOP EXEC дважды (с подтверждением)исполнение остановилось, статус INACTIVE; одиночное нажатие БЕЗ подтверждения ничего не сносит
  • RTE PLAN(Если есть второй корабль) пересесть при активном маршрутепредупреждение КОРАБЛЬ ИЗМЕНЁН — ПЕРЕСТРОЙ
БЛОК 5DIR и PC CLIP
  • DIRНажать клавишу DIR, затем LSK у NEAREST SCOOPABLEфлэш ПОИСК…, затем карточка кандидата: система, класс звезды, LY
  • PC CLIPНа ПК скопировать имя системы (Ctrl+C на Inara/Spansh), на приборе нажать кнопку PC (рядом с CPY/PST)имя появилось в скретчпаде; дальше LSK у DEST на RTE PLAN — и можно строить
  • PC CLIPСкопировать на ПК картинку (не текст), нажать PCфлэш БУФЕР ПК ПУСТ, ничего не зависло

Отчёт соберёт все «НЕ ОК» с комментариями — вставьте его в чат. К сбоям приложите logs/autopilot.log и скрин MCDU.
