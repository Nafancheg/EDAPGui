# Проект эргономической раскладки MCDU Elite Dangerous

## ЭТАП 1 — Информационная архитектура

### 1.1 Легенда 12 функциональных клавиш

| Клавиша | Страница | Назначение (1 строка) | Статус |
|---------|----------|-----------------------|--------|
| **DIR** | DIR | Прямой прыжок: ближайшая заправочная, ближайшая система, ввод цели | Активна |
| **PROG** | PROG (фазовая) | Основная полётная страница; фазы DEPART→CLIMB→CRUISE→APPROACH→ARRIVAL→LANDING (boot default) | Активна |
| **PERF** | PERF | Тюнинг RPY-кривых, автотюн, сохранение | Активна |
| **INIT** | INIT | Преполётный дом: подтверждение маршрута, выбор корабля, быстрый вход во все разделы | Активна |
| **DATA** | DATA | Справочные данные: EDSM-инфо о системе, результаты сканов | Активна |
| **F-PLN** | F-PLN (ROUTE) | Активный маршрут: список систем, быстрый режим, информация о системе | Активна |
| **RAD NAV** | – | Прямого аналога в ED нет | **INOP** |
| **FUEL PRED** | FUEL PRED | Прогноз и управление топливом, заправка; 🟢🟡🔴 annunciator | Активна |
| **SEC F-PLN** | SEC F-PLN | Резервный маршрут: выбор профиля, активация, сравнение | Активна |
| **ATC COMM** | – | Резерв под будущие станционные comms | **INOP** |
| **MCDU MENU** | MCDU MENU | Корень настроек: голос, оверлей, случайность, logout, hotkeys; подстраница MAINT | Активна |
| **AUTO TUNE** | – | Auto-tune RPY живёт на PERF; отдельных функций нет | **INOP** |

### 1.2 Дерево навигации

Глубина 2 уровня.

**Корневые страницы** (доступ по функц. клавише):  
PROG (boot default), INIT, F-PLN, SEC F-PLN, DIR, FUEL PRED, PERF, DATA, MCDU MENU.

**PROG** – главная фазовая страница:
- Содержит 6 фаз, переключаемых стрелками `←`/`→` или `R6 NEXT PHASE>`.
- Каждая фаза показывает свои органы (LSK). Листание фаз циклично в порядке взлёт→посадка.
- Активная фаза подсвечивается автоматически по `ship_status/ap_mode`; ручное листание не запрещено.

**Подстраницы** (доступ через R6 NEXT PAGE / LSK):
- **FUEL PRED** → подстраница REFUEL SOURCE (2-й уровень).
- **MCDU MENU** → подстраница MAINT (dev/debug), а MAINT может иметь 2 страницы листанием `R6 NEXT PAGE`.
- **F-PLN** многостраничный список маршрута, листается `←`/`→` (или `R6 NEXT PAGE`), но не создаёт новых страниц в дереве.

**Глубина часто используемых функций**:
- FSD (CRUISE) — на PROG (0 нажатий при активной фазе).
- Supercruise (APPROACH) — переключиться на фазу APPROACH (1 нажатие `→`).
- Контроль топлива — FUEL PRED (1 нажатие от любой страницы).
- Остановка — красная кнопка STOP ALL (всегда доступна).

### 1.3 Постоянные элементы header/footer (везде)

- **Header (2 строки):**
  - Строка 1: слева имя страницы, справа индикатор контекста (`фаза`, `N/M →`).
  - Строка 2: слева `AP: <ap_state>`, справа `MODE <ap_mode>`.
- **Footer:** scratchpad (ввод/правка, CLR, вставка).
- **Annunciator LED:** Только на клавишах FUEL PRED (топливный статус) и PROG (ассист активен).

## ЭТАП 2 — Структура страниц

### 2.1 PROG (фазовая страница)

**Навигация:** стрелки `←`/`→` — предыдущая/следующая фаза; `R6` подпись `NEXT PHASE>`; `L6` пусто (корневая). Активная фаза автоопределяется по `ship_status/ap_mode`.

**Фазы и их концептуальный состав:**

#### DEPART
- **Назначение:** Отстыковка, взлёт, первичная тяга.
- **Строки:**
  - `L1` Undock / Launch [A], `R1` статус корабля (пристыкован/взлёт).
  - `L2` Throttle 0% [A], `R2` —
  - `L3` Throttle 50% [A], `R3` активный маршрут (пункт назначения)
  - `L4` Throttle 100% [A], `R4` кол-во прыжков
  - `L5` —, `R5` —
  - `L6` —, `R6` NEXT PHASE>

#### CLIMB
- **Назначение:** Выход в суперкруиз, выравнивание на цель.
- **Строки:**
  - `L1` Align to Target [A], `R1` цель (след. система)
  - `L2` Throttle 50% [A], `R2` дистанция до цели
  - `L3` Throttle 100% [A], `R3` —
  - `L4` —, `R4` —
  - `L5` —, `R5` —
  - `L6` —, `R6` NEXT PHASE>

#### CRUISE (основная рабочая фаза)
- **Назначение:** Прыжки по маршруту, сканирование.
- **Строки:**
  - `L1` **FSD Route Assist** [T] (главный тумблер), `R1` прогресс: `jump_cnt/total`
  - `L2` DSS / Honk [A], `R2` осталось прыжков / ETA
  - `L3` FSS scan [A], `R3` пройдено LY
  - `L4` ELW Scanner [T], `R4` текущая система (star class)
  - `L5` —, `R5` —
  - `L6` —, `R6` NEXT PHASE>

#### APPROACH
- **Назначение:** Суперкруиз к станции/сигналу, сброс.
- **Строки:**
  - `L1` **Supercruise Assist** [T], `R1` дистанция до дропа
  - `L2` Align to Target [A], `R2` цель (станция/планета)
  - `L3` —, `R3` —
  - `L4` —, `R4` —
  - `L5` —, `R5` —
  - `L6` —, `R6` NEXT PHASE>

#### ARRIVAL
- **Назначение:** Стыковка или переход к посадке.
- **Строки:**
  - `L1` Request Docking [A], `R1` статус стыковки
  - `L2` Dock [A], `R2` тип цели (станция/планета)
  - `L3` —, `R3` —
  - `L4` —, `R4` —
  - `L5` —, `R5` —
  - `L6` —, `R6` NEXT PHASE> (к LANDING)

#### LANDING (LND)
- **Назначение:** Посадка на планету (план/бэкенд).
- **Строки:**
  - `L1` Drop to Orbital Cruise [A], `R1` Altitude [V]
  - `L2` De-orbit / enter Glide [A], `R2` Lat/Long [V]
  - `L3` Glide (readout), `R3` Heading [V]
  - `L4` Surface approach [A], `R4` Distance to target [V]
  - `L5` Target: POI/marker [A] или Target: coordinates [E], `R5` Bearing [V]
  - `L6` Final descent / touchdown [A], `R6` NEXT PHASE> (цикл к DEPART)

### 2.2 INIT (дом)

**Клавиша:** INIT.  
**Навигация:** `L6`, `R6` пусты (навигация не требуется).  
**Строки:**
1. `L1` [A] **ACTIVE ROUTE** (переход в F-PLN), `R1` кратко пункт назначения/прыжки
2. `L2` [A] **SELECT SHIP**, `R2` имя текущего корабля [V]
3. `L3` [A] **PROG**, `R3` текущая фаза [V]
4. `L4` [A] **FUEL PRED**, `R4` топливо % и статус
5. `L5` [A] **PERF**, `R5` —
6. `L6` пусто, `R6` пусто

### 2.3 F-PLN (активный маршрут)

**Клавиша:** F-PLN.  
**Навигация:** `←`/`→` (или `R6 NEXT PAGE`) — листание страниц списка. `L6` пусто (корневая).  
**Строки (страница 1 и далее):**
1. `L1` **FAST TRAVEL** [T], `R1` пункт назначения / всего прыжков [V]
2–5. Список систем (листаемый):
   - `L(n)` [A] система N (per-system info), `R(n)` класс / scoopable / дистанция LY
6. `L6` пусто, `R6` NEXT PAGE (или символ `→`)

При нажатии L на системе временно показывает подробную инфу (класс, scoopable) возможно в scratchpad или в правой части той же строки — детали реализации.

### 2.4 SEC F-PLN (резервный маршрут)

**Клавиша:** SEC F-PLN.  
**Навигация:** `L6` пусто (вернуться некуда), `R6` пусто.  
**Строки:**
1. `L1` **PROFILE** [T] (Fuel-safe ↔ Fast), `R1` сводка: прыжки / LY
2. `L2` **ACTIVATE SEC** [A], `R2` статус (резерв готов)
3. `L3` **COMPARE** [A], `R3` — (по нажатию заполняет строки 4-5 сравнением)
4. `L4` (сравнение: primary jumps/LY), `R4` (secondary jumps/LY)
5. `L5` (сравнение: топливные остановки), `R5` —
6. `L6` пусто, `R6` пусто

### 2.5 DIR (прямой прыжок)

**Клавиша:** DIR.  
**Навигация:** без листания.  
**Строки:**
1. `L1` **NEAREST SCOOP** [A], `R1` дистанция (если доступно)
2. `L2` **NEAREST SYS** [A], `R2` дистанция
3. `L3` **DIRECT TO** [E] (ввод системы в scratchpad → LSK), `R3` цель после ввода
4–6 пусто.

### 2.6 FUEL PRED (топливо)

**Клавиша:** FUEL PRED (annunciator LED).  
**Навигация:** `R6 NEXT PAGE` → подстраница REFUEL SOURCE; `L6 RETURN` (если пришли из INIT).

**Основная страница:**
1. `L1` **REFUEL THRESH** [E] (ввод %), `R1` текущий порог
2. `L2` **ACTIVATE REFUEL** [A], `R2` Current star: class + scoopable [V]
3. `L3` —, `R3` **FUEL %** [V] (цветной индикатор)
4. `L4` —, `R4` **FUEL TONS** [V]
5. `L5` —, `R5` **JUMPS UNTIL REFUEL** [V]
6. `L6` RETURN, `R6` NEXT PAGE (→ REFUEL SOURCE)

**Подстраница REFUEL SOURCE:**
1. `L1` **NEAREST STATIONS** [A] [план], `R1` (дистанция)
2. `L2` **NEAREST REFUEL POINTS** [A] [план], `R2`
3. `L3` **STAR IN THIS SYSTEM** [A], `R3` scoopable
4–6 пусто, `L6` RETURN, `R6` пусто.

### 2.7 PERF (характеристики)

**Клавиша:** PERF (уже реализована, проверка контракта).  
**Навигация:** вероятно, одна страница.  
**Предполагаемая структура (с соблюдением лево=действия):**
1. `L1` AUTO-TUNE RPY [T], `R1` состояние (On/Off)
2. `L2` CURVE EDITOR [A] (открыть редактирование), `R2` текущие значения (например, Roll)
3. `L3` SAVE ALL [A], `R3` Pitch value
4. `L4` LOAD ALL [A], `R4` Yaw value
5. `L5` —, `R5` —
6. `L6` RETURN, `R6` NEXT PAGE (если есть доп. страницы)

*Если текущая реализация нарушает лево/право, указать в замечаниях.*

### 2.8 DATA (справочные данные)

**Клавиша:** DATA.  
**Навигация:** если данных много — `R6 NEXT PAGE` листание; `L6 RETURN`.  
**Строки:** все правые ячейки — индикация [V]; левые пусты.  
Пример:
- `R1` System name / EDSM info
- `R2` Star class, planets
- `R3` FSS/DSS scan results (bodies)
- …  
При отсутствии данных: `NO DATA`.

### 2.9 MCDU MENU + MAINT (настройки)

**Клавиша:** MCDU MENU.  
**Навигация:** `L6 MAINT>` переход на подстраницу MAINT; `R6` пусто.

**Страница MENU:**
1. `L1` VOICE [T], `R1` On/Off
2. `L2` OVERLAY [T], `R2` On/Off
3. `L3` RANDOMNESS [T], `R3` On/Off
4. `L4` AUTO LOGOUT [T], `R4` On/Off
5. `L5` HOTKEYS [T], `R5` On/Off
6. `L6` **MAINT>** [A], `R6` пусто

**Подстраница MAINT (первая):**
1. `L1` CV VIEW [T], `R1` On/Off
2. `L2` DBG OVERLAY [T], `R2` On/Off
3. `L3` DBG OCR [T], `R3` On/Off
4. `L4` DBG IMAGES [T], `R4` On/Off
5. `L5` ACT-ELITE-EACH-KEY [T], `R5` On/Off
6. `L6` RETURN, `R6` NEXT PAGE (→ MAINT 2/2)

**MAINT страница 2 (тайминги и конфиг):**
1. `L1` MOD DELAY [E], `R1` значение (ms)
2. `L2` DEF HOLD TIME [E], `R2` значение
3. `L3` REPEAT DELAY [E], `R3` значение
4. `L4` RELOAD BINDINGS [A], `R4` —
5. `L5` AUTO-ASSIGN KEYS [A], `R5` —
6. `L6` RETURN, `R6` пусто

*Load All / Save All settings* можно разместить на MAINT 2 дополнительно, если есть место, или вынести на MENU, но соблюдая приоритеты. Оптимально: на MAINT 2 заменить одну из кнопок конфига на LOAD ALL/SAVE ALL. Учитывая объём, можно детализировать:  
- L4 LOAD ALL [A], L5 SAVE ALL [A].  
- Refresh game settings можно опустить или добавить на MAINT 1.

## Дополнительно

### План декомпозиции перегруженного INIT/DIR

Текущие функции, сваленные на одном экране, распределены:
- FSD/SC → фазы CRUISE/APPROACH на PROG.
- Throttle → DEPART, CLIMB.
- Топливо/звезда → FUEL PRED.
- Fast Travel → F-PLN.
- Прыжки, ETA, цель → PROG (CRUISE, APPROACH).
- Stop All → отдельная красная кнопка.

### Обоснование ключевых решений

1. **Фазовая организация на PROG** (приоритет: эргономика/безопасность) — исключено одновременное соседство FSD и SC, каждый режим в своей фазе; NEXT PHASE> следование конвенции MCDU.
2. **Жёсткое разделение лево=действия, право=параметры** (конвенция) — мышечная память, быстрый взгляд.
3. **R6 NEXT, L6 RETURN на всех страницах** (конвенция) — одинаковое поведение, снижает ошибки.
4. **STOP ALL отдельной кнопкой** — аварийная функция не может быть на LSK, случайное нажатие недопустимо (безопасность).
5. **LED на FUEL PRED и PROG** — периферийная индикация критических параметров без открытия страницы.

### Приоритет реализации

1. **PROG** (CRUISE, APPROACH) — главный автопилот, FSD/SC, прогрев.
2. **FUEL PRED** — контроль топлива и дозаправка, annunciator.
3. **F-PLN** — активный маршрут (уже частично реализован, привести к контракту).

Все изменения строго в рамках зафиксированных решений, без новых клавиш и без нарушения конвенции реального MCDU.
