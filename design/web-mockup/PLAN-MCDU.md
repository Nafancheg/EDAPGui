# План: переделать EDAutopilot в прибор MCDU (Airbus A320)

Тона и цвета оставить как в текущем `EDAutopilot.dc.html` (янтарь на тёмном + бирюза/зелёный, точечная ЭЛТ-матрица, свечение).

## Шаги
1. **Начать с этого:** создать новый файл `EDAutopilot MCDU.dc.html` (скопировать логику из `EDAutopilot.dc.html`), пересобрать вёрстку в вертикальный прибор-корпус. Старый файл не трогать до готовности.
2. **Корпус прибора:** единый вертикальный блок с тёмным пластиковым бевелем, скруглениями, тенями/бликами — прибор, а не плоская панель.
3. **ЭЛТ-экран A320:** заголовок сверху, парные поля слева/справа, LSK-стрелки по бокам экрана, точечная матрица + свечение, текущие тона.
4. **Блок функциональных клавиш:** DIR, PROG, PERF, INIT, DATA / F-PLN, RAD NAV, FUEL PRED, SEC F-PLN, ATC COMM, MCDU MENU + BRT/DIM.
5. **Стрелки + буквенная клавиатура:** AIRPORT и ←↑→↓, полная сетка A–Z, часть клавиш в рамке-боксе как на референсе.
6. **Цифровая клавиатура:** 1-9, 0, +/-, точка, SP, OVFY, CLR. Сохранить интерактив: скретчпад, лог (скролл + автопрокрутка к последней записи), тумблеры режимов.
7. **Адаптив:** прибор масштабируется/центрируется. Сохранить tweaks: connected, shipName, shipType, version.

## Что уже готово в текущем файле
- Воссоздан веб-интерфейс EDAutopilot (амбер на тёмном, моно).
- Интерактив: тумблеры режимов, кейпад+скретчпад, степпер Sun Pitch, дропдаун Throttle, Auto-Tune, Align, Edit-кривые, Save/Load — всё пишется в лог с таймстампом.
- Лог: фикс. высота 200px, скролл, автопрокрутка вниз к последней записи.
- Экраны на ЭЛТ-шрифте VT323 + точечная матрица; кнопки на обычном моно.
- Tweaks: connected, shipName, shipType, version.
