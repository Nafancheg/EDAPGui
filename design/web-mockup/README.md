# EDAutopilot — макет веб-интерфейса (MCDU)

Интерактивный прототип переработанного GUI EDAutopilot в виде вертикального
прибора Airbus A320 MCDU (Multifunction Control Display Unit — бортовой
компьютер). Целевой форм-фактор — планшет рядом с игрой (см. память
web-ui-direction: headless-сервер + web MCDU).

## Файлы

- `EDAutopilot-MCDU.dc.html` — интерактивный прототип (формат компонента
  `.dc`): вертикальный корпус прибора с ЭЛТ-экраном, LSK по бокам,
  функциональными клавишами, клавиатурой A–Z и цифровым блоком; рядом —
  отдельная панель MESSAGE LOG.
- `support.js` — библиотека рантайма, нужна для рендера компонента `.dc`.
- `PLAN-MCDU.md` — план, по которому собирался прибор (выполнен).
- `uploads/mcdu-preview.webp` — превью итогового макета.
- `uploads/pasted-*.png` — фото реального A320 MCDU, послужившего
  визуальным референсом.

## Заметки по дизайну

- Палитра: почти чёрный фон (`#08080a`), янтарный акцент (`#E8973E` —
  классический цвет фосфорных дисплеев), голубой (`#5f96d6`) для заголовка
  экрана и бирюзовый (`#5aa9c9`) для значений-действий.
- Шрифты: `IBM Plex Mono` для корпуса/клавиш, `VT323` (пиксельный CRT)
  для экрана и лога.
- Экран использует внутреннюю тень, точечную «ЭЛТ-матрицу»
  (radial-gradient) и свечение текста; корпус — тёмный пластиковый бевель
  со скруглениями и бликами.
- Семантика MCDU как в A320: 6 парных полей L/R с заголовками, LSK-кнопки
  по бокам экрана (при непустом скретчпаде LSK вводит его значение в поле,
  иначе выполняет действие поля), скретчпад внизу экрана, блок
  функциональных клавиш (DIR, PROG, PERF, …, MCDU MENU, AUTO TUNE).
- Реализована страница 1/2 (режимы-ассисты + быстрые параметры).
  Страница 2/2 (RPY-тюнинг, кривые roll/pitch/yaw) в макете не нарисована —
  старый горизонтальный дашборд с этим блоком остался в git-истории
  (`EDAutopilot.dc.html`, удалён в пользу прибора).

Это только визуальный/интерактивный референс; в Python-приложение он не
встроен.
